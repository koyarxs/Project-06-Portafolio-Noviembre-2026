# Hero technology marks

The hero uses local SVG assets, so logos remain sharp at any device pixel ratio without relying on a third-party image request at runtime. Brand names are rendered as HTML text.

Source: https://github.com/devicons/devicon (MIT; license included at `apps/web/public/images/stack/LICENSE`). Brand marks remain the property of their respective owners.

Added AWS and Google Cloud from the `v2.17.0` tag, and Azure, Prisma and Docker from `master` on 2026-11-13:

- `amazonwebservices/amazonwebservices-original-wordmark.svg`
- `googlecloud/googlecloud-original.svg`
- `azure/azure-original.svg`
- `prisma/prisma-original.svg`
- `docker/docker-original.svg`

Portfolio cards also use `angular/angular-original.svg` and `django/django-plain.svg` from Devicon `v2.17.0`, downloaded on 2026-11-13. These marks describe individual projects; they do not change the hero's personal stack.
