# Navigation design and attention hours

Three levels inspired by the owner's reference: dark service/attention strip, centered original YB Veltrix logo, and a white navigation row. The logo uses the existing reference asset without recoloring or redrawing it.

Hours explicitly supplied by the owner: Monday–Friday, 08:00–20:00, America/Santiago. The status means within/outside attention hours, not live online presence. It updates each minute after hydration. No phone or email was added.

Desktop keeps the navigation row visible as the upper two rows scroll away; mobile has a collapsible menu and the existing accessible Services dropdown. Screenshots: images/navbar-premium-desktop.jpg and images/navbar-premium-mobile.jpg.

Validated with TypeScript, seven timezone/boundary checks, and desktop/mobile browser inspection.
